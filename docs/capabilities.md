# 能力与限制

| 能力       | 当前实现                                                                       | 尚未实现或未验证                                 |
| ---------- | ------------------------------------------------------------------------------ | ------------------------------------------------ |
| 手动记账   | 收入、支出、退款、转账；日期、金额、备注、标签；编辑、回收站恢复               | 未对标原生键盘操作耗时                           |
| 支付消息   | Android 支付通知候选，本机加密、手动核对及重复关联                             | 真实支付模板、锁屏、厂商后台及重启行为待真机验收 |
| 导入       | UTF-8/GB18030 CSV、XLSX、XLS，表头与字段映射                                   | PDF、图片、OCR、全银行格式覆盖                   |
| 文件范围   | 人民币，Excel 单工作表，单文件 10 MB/15,000 行                                 | 外币账单导入、超大文件流式解析                   |
| 去重核对   | 文件 SHA-256、同源流水号；跨平台同额同账户候选；多候选人工关联、独立确认及撤销 | 真实大样本准确率评估；多个候选须人工选择         |
| 分类与标签 | 新增、改名、排序、归档；商户规则；备注建议与多标签检索                         | 标签层级、机器学习训练                           |
| 流水整理   | 搜索、日期、来源、类型、账户、成员及报销组合筛选；合计、批量分类与分组删除     | 保存筛选方案                                     |
| 收支统计   | 退款抵扣支出；转账/还款不计收支；任意日期、全年、分类与标签图表                | 原消费与退款自动关联、会计报表                   |
| 预算与日历 | 自定义账期，整月/分类预算；自然月日历及每日明细                                | 预算自动结转、原生系统日历接入                   |
| 周期记账   | 日/周/月/年规则，到期补记及去重；共享账本服务端调度                            | 本地账本在网页关闭时的后台执行                   |
| 资产管理   | 资产/负债/净资产，余额基准、账户关联、校准、归档及外币折算                     | 银行实时余额、投资自动估值                       |
| 多账本     | 独立账本，新增、改名、切换、归档/恢复；共享账本邀请与权限角色                  | 跨设备生产环境协作验收                           |
| 保存与隐私 | Web 大值 IndexedDB、Android 加密 SQLite；密码保护、金额隐藏及过期写入保护      | 服务端端到端加密、密码找回                       |
| 同步       | 自托管账号，用户隔离，页面打开时自动同步，revision 冲突保留两边                | 公网托管、跨设备实机验收、记录级自动合并         |
| 备份与导出 | CSV/Excel；含附件 .hamster 归档及旧 JSON 恢复到新账本                          | 跨 schema 版本增量迁移                           |
| 个性化     | 暖棕/绿/深色主题，前台每日提醒                                                 | 关闭网页后的系统通知                             |
| PWA/App    | 离线 Web 应用壳、记账快捷入口及 Android 原生安装包                             | 原生桌面小组件、商店发布及 iOS 客户端            |
| 撤销       | 当前会话最后一次修改                                                           | 刷新后操作历史                                   |

示例与验收数据均为虚构。`apps/web/public/samples` 三份 CSV 合计 9 条交易；人工关联支付宝和招行的 36 元消费后，净支出 268.80 元、收入 18,500.00 元。28 元退款抵扣支出，充值和还款不计收支。

功能对齐依据和证据见 [鲨鱼记账对齐说明](shark-parity.md)。测试通过只证明列出的行为，不等于全部银行格式、终端和业务场景已通过验收。

本轮大账本、筛选和核对证据见[优化记录](ledger-optimization-2026-10-15.md)。Web 保存格式兼容及回退要求见[存储说明](browser-storage.md)。
