# 验证范围

仓库检查由 `npm run check` 运行，包含共享包和 Web 类型检查、ESLint、依赖边界、测试、Web 构建以及 Sites 静态打包契约。

- 账务测试覆盖精确金额、错误日期、分列收支、退款、还款、未知方向、外币拒绝、自定义规则与去重边界。
- 存储契约测试覆盖示例与个人隔离、既有键兼容、损坏数据、未知版本、写失败和账本选择。
- Node 环境测试确认导入器不需要浏览器全局对象。
- Web Hook 测试覆盖异步加载、提交撤销、损坏数据停止写入和保存失败时不更新界面状态。

原型截图与浏览器交互验证记录位于 [设计检查](design/qa.md)。当前结构迁移没有重新操作已交给用户控制的浏览器页面，因此不把单元测试和构建结果说成浏览器复检通过。

App 安装包、原生设备、多币种、加密备份、真实金融平台数据和全部银行导出版本均未验证。
