# 导入 CSV 账单与调整字段

选择账单文件后，先看识别条数、表头行和数据预览，再确认导入。CSV 在本机解析，只有主动开启账本同步后才会上传账本数据。

## 自动识别

支持 UTF-8 / GB18030 CSV，以及既有的 XLSX / XLS 单工作表。系统会在文件内寻找表头，跳过开头的说明与空行；不再只检查前 100 行。CSV 中间的空行会保留，因此手动选行与解析后的表格行号一致。

日期别名包括「交易时间」「记录时间」「记账时间」「交易日期」「付款时间」等。列名不匹配时，会参考表头后面的数据样例，建议日期、金额及明确的收支方向；多个候选数字列不会强行选择。流水号、账号、余额和手续费等列不作为金额的自动候选。

重复字段名或根据数据推断出的字段需要确认。未确认时，预览记录保持待确认，不能导入；没有可信表头时不会把第一笔交易悄悄当成表头。日期和金额缺失、列号越界或必要字段指向同一列时，会显示错误。

## 手动调整

1. 点击文件旁的「调整字段」。安卓端入口为「核对字段」。
2. 在「表头所在行」填写行号，点击「应用表头行」。可以选择文件内任意有效行，不受原来前 30 行选项的限制。
3. 为交易时间、金额、收支方向、备注、分类、账户等字段选择对应列。每个选项显示列号、列名和数据样例。
4. Web 下方的原始数据表可横向滚动，用于核对列和值。安卓在每个选项中显示样例。
5. 有自动推断或重复列提示时，核对后点击「确认字段映射」。修改映射会撤销此前的确认。
6. 检查交易预览，再点击「确认导入」。也可以点击「重新自动识别」重新建议表头和字段。

默认付款账户只在没有映射到账户值时使用。不要把支付平台名称直接当作实际付款账户。

## 保留的数据与校验

文件提供的分类、备注和标签会保留；已保存的商户分类规则仍优先，分类为空时才使用常见商户规则。缺少独立商户列时，使用备注作为交易名称。来源等未映射列保存在原始流水中。

重复表头和明确的合计行不当作交易。格式错误的交易仍单独报告，不会作为零金额入账；只能在用户明确勾选跳过错误行后导入其他有效记录。金额继续使用整数分，未知收支方向仍需核对。当前仅支持人民币。
