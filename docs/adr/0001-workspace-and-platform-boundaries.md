# 0001：共享 TypeScript 业务包，隔离平台副作用

状态：已采用。日期：2026-09-30。

原型把文件读取、账本规则和浏览器存储放在同一目录。未来增加 App 时，这种结构容易把 DOM 和同步存储假设带进原生客户端。

采用 npm workspaces，将 Web、账务核心、表格解析和设计变量分开。共享包只暴露普通数据与异步存储协议，平台层负责文件系统、解码、哈希、持久化和导出。

继续沿用原有账本序列化格式与浏览器键名。异步读写使 Web 增加了初始化和保存中的状态；读失败时停止写入，防止覆盖无法解析的数据。

暂不创建原生工程或通用 UI 组件库。选定 App 平台后再决定 UI 技术，避免把 Web 组件接口误当作原生接口。暂不引入 monorepo 任务框架，因为现有 workspace 命令已经覆盖构建和验证。
