# PostgreSQL 迁移验证，2026-10-12

服务端运行路径已从同步 SQLite 改为异步 PostgreSQL。客户端 HTTP 协议与账本金额模型保持兼容，Android SQLCipher 离线账本不迁移。SQLite 仅保留为显式旧库导入源及合成迁移测试格式。

连接池通过异步上下文使事务内所有查询复用同一连接。账本操作、成员变更、模型自动入账设置和附件引用检查使用账本行锁，版本条件与请求唯一约束保留；附件清理不会与新增账本引用交错。周期执行在持久标识与账本版本保护下支持多个调度实例。

`npm run check` 通过 255 项测试：187 项 Vitest、55 项服务端、4 项 Sites、9 项依赖检查。原有 50 项服务端用例已迁至真实 PG，新增测试验证事务失败回滚与连接释放、跨连接版本冲突及幂等重放、双实例周期调度，以及 17 张业务表的旧库导入和失败回滚。

合成旧库导入核对了账本版本与金额、附件字节、模型凭据解密、会话、Token、幂等回执、调度记录和排序序列。预检查不写目标业务数据，源库文件字节保持不变；非空目标拒绝覆盖，部分插入失败后全部回滚。没有对工作区原有 `data` 目录执行迁移或删除。

本机 ARM64 Docker 镜像构建通过，运行验证覆盖 PostgreSQL 非超级用户连接、HTTP 健康、保存与读取、容器重启、`pg_dump` / `pg_restore` 到独立数据库，以及模型主密钥独立归档恢复。恢复后账单、附件哈希、登录状态、Token 与幂等回执保留。镜像 SHA256：`9766b24603d44504f61022a3b43dda1861d523d2ab8e8ee6397486d0145027e3`。

初次 Docker Hub 拉取遇到连接超时，单独拉取官方基础镜像后重试成功。容器测试还发现初始化期间 Unix socket 可提前报告可用，健康探测已改用 TCP，避免迁移任务过早连接。

CI 的 Node 22/24 检查使用 PG 服务，容器工作流增加独立运行与恢复测试。本地结果不代表 CI、正式镜像发布或现有部署已切换。连接、迁移和备份恢复操作见 [自托管说明](self-hosting.md)与[容器运维说明](container-operations.md)。
