# 资产账户与账单关联

在“资产管理”添加资产或负债账户，填写你确认过的余额与确认时间。净资产由总资产减总负债得到，不能用月度收支结余替代。

## 总览与资产变化

Web 和 Android 的总览页显示当前净资产、总资产、总负债和本月净资产变化。首页隐藏金额的偏好也适用于这些数值。

资产管理按所选估值日展示余额。本月变化与上月最后一天的余额比较，账户列表使用原币金额，净资产使用人民币估值。两端均可按账户名称、类型和别名搜索，并单独显示已归档账户。

净资产趋势展示近六个月内的月末及起止日估值。起点不会早于当前未归档账户各自最早的已知余额基准。归档账户在整个比较区间内均不参与计算，当前数据没有账户归档时间的历史快照。

缺少月初以前的基准时，变化显示为“暂无可比数据”，不会把首次填写的余额当成资产增长。缺少汇率时，合计标为“已估值净资产”，并提示未估值的币种；本月变化需要两个时点的汇率齐全。

## 余额如何更新

账户余额以最近一次手动确认的余额为基准，只累计基准之后、当前时间之前的已确认流水。

- 资产账户：收入和退款增加余额，支出减少余额。
- 信用卡或贷款账户：消费增加负债，退款或还款减少负债。
- 转账：设置转出与转入账户后，同时更新两端余额，不计收入或支出。还款从资产账户转入负债账户，净资产保持不变。
- 待确认和重复记录不参与余额变化。转账账户不完整时，两端都不更新，避免猜测资金方向。
- 信用卡预存余额视为资产，透支的资产账户余额视为负债，净资产仍按正负价值汇总。

“校准余额”用于重新对齐银行余额或投资估值。表单显示所选确认时点的账面余额、校准差额和校准后余额。差额只调整账户余额，不创建收入或支出。确认时间之前的账单保留为历史记录，不再次叠加。

首次校准旧账户时，原有余额基准会一并保留。同一确认时点多次更正，以最后保存的基准计算余额，原始维护记录继续保留。已有数据中从未保存过的旧基准无法恢复。

## 账户明细

账户详情区分两类记录，均支持月份筛选，每页最多显示 20 条。

- **余额变动**：展示建立基准、已确认流水和余额校准。每条记录显示账户原币变动额及变动后的余额。正数表示账户余额增加，负数表示减少；负债减少代表偿还负债。
- **关联账单**：展示所选估值日以前的关联账单，包括待确认及基准以前的记录，不含重复或已删除记录。它们是否影响余额仍由状态与基准时间决定。

账户详情的转账入口预选转出账户。负债账户的还款入口预选转入账户，保存前仍需确认两端账户和金额。账户详情和列表中的余额始终使用所选估值日对应的基准。

## 如何关联账单

点击单条记录的“详情”，选择对应的资产账户。收入、支出、退款使用实际收付款账户；转账和还款需要明确两端账户。

导入账单可按账户名称或别名自动匹配。例如支付平台记录的付款方式是“招商银行 · 6628”，应匹配银行卡账户，而不是仅因账单来源为支付宝就匹配支付宝余额。

名称或别名冲突会阻止保存，避免将一条流水自动关联到错误账户。手动选择“不关联资产账户”后，自动匹配不会覆盖这个选择。账户改名、调整别名和归档会保留已有的历史关联。

## 维护账户

- 编辑账户名称、类型、别名及余额基准。
- 从账户详情查看全部账期或指定月份的余额变动与关联账单，打开任意记录详情。
- 归档账户后保留历史资料，但从资产总额中移除；可恢复，并支持当前会话撤销。
- 已有账户不能直接从资产切换为负债，避免历史流水的符号被反转。应新增对应性质的账户。

## 数据兼容与边界

既有账本没有账户字段时按空账户列表读取。新增字段为兼容扩展，账本版本和浏览器存储键保持不变。已确认账单关联保存在账户 ID 中，显示名称不再是唯一标识。

账户支持多币种，余额按账户原币计算，资产合计折算为人民币。余额依赖手动基准与已导入的数据，没有银行直连或自动投资估值。对同一笔转账或还款，只关联一条主流水，其重复记录应保持为重复状态。
