# Android 金额强调色

收入使用鼠尾草绿，支出使用陶土红。总览、账单列表、账单详情、收支报表和日历统一使用金额组件，金额采用半粗体和等宽数字，保留原有正负号、类型文字与数值格式。

| 金额语义                                                     | 浅色       | 深色       |
| ------------------------------------------------------------ | ---------- | ---------- |
| 收入、退款等正向回款                                         | `#25664d`  | `#94d1ad`  |
| 支出                                                         | `#a3432f`  | `#ffb09c`  |
| 结余、资产变化、转账、不计收支、未确认、重复、已删除与零金额 | 主题中性色 | 主题中性色 |

退款继续按原有业务规则抵减支出，使用正向色不会将其计入收入。结余和净资产期间变化使用主题中性色，不按正负映射到收入／支出。净资产曲线使用主题色，“净增／净减／持平”文字表达方向。资产余额继续使用原有展示方式。

选择隐藏首页金额时，数字和对应的强调色一起隐藏，避免通过颜色透露结余方向。窄屏或大字体下，收入与结余按可用宽度纵向排列，避免把金额拆成两行。分类进度条随当前收支类型变色，日历热力底色使用支出色的渐变透明度，日期文字保持当前主题的高对比色。

颜色保存在共享设计 tokens，显示规则保留在 Android UI 层。金额计算、入账规则、同步和备份格式保持不变。

## 验证

2026-10-11，Android API 36 ARM64 模拟器，常规宽度约 411dp，窄屏 320dp 配合 1.3 倍字体。

- 同一示例账本在调整前后均为 124 笔流水，本期支出 8,642.30 元、收入 18,500.00 元、结余 9,857.70 元。
- 浅色与深色总览的金额、正负号和类型文字保持一致，颜色清楚区分收入与支出。
- 列表中确认的支出为陶土红、工资收入为绿色；待确认记录保持中性色。详情页继续显示 `+`、`−` 和收入或支出标签。
- 报表切换收入和支出时，金额及分类条形图使用对应颜色。
- 隐藏金额后占位符使用中性色。
- 320dp / 1.3 倍字体下，收入 18,500.00 元和结余 9,857.70 元均保持完整一行。
- 14 组强调色与页面、卡片及选中背景的对比度计算均大于 4.5:1，最低为 4.9309:1。详细数值见 [contrast.json](evidence/android-amount-colors/contrast.json)。这是本次金额强调色的计算结果，不代表整应用的无障碍认证。

截图位于 [android-amount-colors](evidence/android-amount-colors/)；`before.png` 为调整前，其余为调整后。

`npm run check` 通过 222 项测试和格式、类型、lint、依赖兼容、架构边界、Web 构建检查。Android ARM64 Release 原生构建通过，测试包使用开发签名。

## 用色依据

- [WCAG 1.4.1 用色](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)：保留文字、形状等颜色之外的识别方式。
- [WCAG 1.4.3 对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)：普通文字与背景至少 4.5:1。

## 2026-10-12 语义调整

总览与收支报表的结余、资产趋势的期间净增／净减统一改为中性色。收入绿、支出红仍只表达已确认收支；转账、零金额和未确认通知保持中性。净资产曲线沿用当前主题色。现有投资买入／卖出没有新增收益涨跌指标，因此不引入证券行情颜色。以后若展示投资收益涨跌，应独立定义红涨绿跌，避免复用收支颜色。
