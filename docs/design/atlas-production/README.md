# 资产图集在 Web 与 Android 的正式入口

以 2026-11-22 的资产图集为设计依据。界面从当前账本读取数据，账户、金额和日期随账本变化。截图使用仓库自带的虚构示例。Web 和 Android 共用估值、账期、图标字段和收支汇总，交互由各自的正式页面负责。

| 图集状态                                                    | 正式入口与行为                                                                                                                                                                                 |
| ----------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| overview、hidden、missing、zero                             | 资产首页展示净资产、总资产、总负债、月变化、资产构成和最近流水。桌面使用面积图，窄屏和 Android 使用比例带。隐藏金额时同步隐藏图表和排行。缺汇率或基准时标明部分估值，无分母时负债率显示「—」。 |
| asset、debt、net                                            | 资产首页进入资产分析／趋势，可切换三个口径，按估值日或上一年度查看。资产和负债有对应的账户排行，可打开账户详情。历史缺失点留空。                                                               |
| account、credit、baseline                                   | 从账户列表或排行进入详情，显示原币余额、基准与变动。可查看关联流水、选择账期、查询基准历史。信用卡使用欠款、还款及预存语义。                                                                   |
| calibrate、transfer、repay                                  | 账户详情进入校准、转账或还款，沿用有预览和账本身份检查的保存流程。                                                                                                                             |
| icons、iconsearch                                           | 编辑或添加账户时选择图标。支持搜索、12 个图标及按类型自动选择，随账户表单保存。                                                                                                                |
| entry、keypad、income                                       | 主工具栏进入「记一笔」，切换收支并挑选分类。Android 分类可打开加减金额键盘，完成后回填草稿，保存仍需单独操作。Web 可用实体键盘或移动浏览器的数字键盘。                                         |
| ledger、search、calendar                                    | 账单页可搜索、过滤并查看按日小计；已有账单日历可选日期查看记录。小计采用当前筛选结果，仅汇总已确认收支。                                                                                       |
| report、week、weekinc、monthinc、yearexp、yearreport、drill | 收支报表支持周、账期、年和自定义范围，方向可切换，分布图可下钻明细，保留退款抵扣和转账单列。                                                                                                   |
| monthbill、yearbill、budget                                 | 收支报表切换到「收支账单」可查看月账单或年账单。选择年度表中的月份回到对应账期。资产或报表可进入预算管理。                                                                                     |

## 实现边界

- 账户可选字段 `icon` 随账本序列化；旧账本未设置时按账户类型显示。旧版客户端可能在重新保存时丢弃新字段。
- 首页小趋势按月内最多七个时点采样，没有历史人民币估值时省略。详细趋势使用独立的历史参考汇率，图中的折线按估值点绘制。
- 动效随系统减少动态效果设置和记账偏好控制。Android 工具栏与表单栏使用 Expo Blur，在 API 31 及以上采样独立的颜色背景，低版本使用透明着色。Web 支持减少透明度时使用实色。
- 安卓金额键盘用于数字、加减和回填。图集上的日期、付款账户、标签和备注对应正式表单字段，凭证管理沿用已保存流水的详情入口。

## 验证

`npm run check` 验证依赖、格式、类型、边界、814 项 Vitest、Web 构建、4 项静态托管测试、67 项服务端测试。新增用例覆盖外币折算、预存与透支、估值缺失、图标与旧账户兼容、跨月账期和键盘加减。

浏览器走查桌面与 390px 窄屏，验证资产构成、隐藏金额、负债排行进入信用卡、图标搜索选中、上年缺少估值、年账单下钻、快捷分类与按日明细。Android 在 API 36 无窗口模拟器上回归，屏幕按 Pixel 11 Pro XL 的分辨率设置为 1344 × 2992，逻辑密度 480 dpi，可用宽度 448 dp。模拟器数据只使用虚构账本。安装包使用开发签名。生产部署、真机性能和全部状态逐图像素对比未验证。
