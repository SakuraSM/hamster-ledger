# 双端图表优化与验证

## 对照方向

- [Actual Budget 报表说明](https://actualbudget.org/docs/reports/)展示了按时间范围查看净资产、现金流和支出分布的方式。本次保留仓鼠记账原有配色与布局，增加净资产范围选择和逐期查看。
- [YNAB 的报表说明](https://www.ynab.com/blog/ynab-reports-and-data)和[移动端收入与支出视图](https://www.ynab.com/whats-new/check-your-income-vs-spending-on-mobile)提供分类占比、分类下钻及多期收支对比。本次在双端报表接入同一份真实账本数据，支持点选分类、查看对应账单和分页。

这些来源用于比较交互和信息层级，不代表功能或视觉完全相同。

## 数据口径

- 收支趋势按已确认、未删除的账单统计，退款抵减支出，转账与还款不计为收支。短范围按日、较长范围按月；未记录收支的日期显示零，涉及超过 120 个自然月则提示缩短范围，不截断后冒充完整趋势。
- 环图仅对正值分类或标签计算占比；退款超过支出的分类单独列出。多标签账单会分别进入各标签，标签合计可能重复。
- 净资产按各日期的账户归档状态、余额基准及当日可用汇率计算。任何活跃账户缺基准或汇率时，该日期留空；没有账户时不显示伪造的零资产。隐私设置开启时不渲染金额、分类名称或图表明细。

## 验证记录

所有截图均使用仓鼠记账内置虚构示例账本。

- Web 同一示例账本、1440 × 1024 视口：[优化前](web-report-before.png)、[优化后](web-desktop-report.png)；[390 × 844](web-mobile-report.png)、[夜间报表](web-night-report.png)。
- Web 实际点选环图的购物扇区，打开该分类中的示例账单；切换近三期后按月展示。320 像素宽下逐一检查 11 个主页面，未出现横向溢出；桌面、手机和夜间报表的 axe A/AA 自动检查未发现违规。
- Android 最终开发签名包在隔离模拟器中验证：[分类环图](android-distribution.png)、[收支趋势](android-cashflow.png)、[一年净资产](android-net-worth.png)和[缺基准日期](android-net-worth-gap.png)。分别点击购物与餐饮扇区，确认选中对应分类；打开示例账单并返回，切换趋势日期后金额与账单一致。
- 模拟器 1.3 倍字体下检查了[净资产趋势](android-net-worth-large-text.png)，随后恢复原字体设置；crash buffer 无崩溃记录。未进行物理设备或人工读屏验收。
- 5 万条合成流水的单次本机计算生成 12 个月分桶，收入与支出合计与现有账本汇总一致；该结果不作为设备性能承诺。
- `npm run check` 通过：801 项 Vitest、67 项 PostgreSQL 服务端测试、4 项 Sites 测试，以及依赖、格式、类型、lint、包边界和构建检查。新增图表组件的专项静态检查通过。
