## 修正记录

1. P2：初版次级文字低于 WCAG AA 对比度。加深通用、表头、侧栏与表单文字；重新扫描总览、导入与手机总览均无 A/AA 违规。
2. P2：图表容器使用 aria-label 但缺少角色。补充 role=group，复扫通过。
3. P2：React StrictMode 下弹窗关闭时焦点没有回到触发按钮。清理时先关闭原生 dialog 再恢复焦点，浏览器复测 Escape 后焦点为“切换账本”。
4. P2：核对列表选中项的辅助文字对比度不足。已改为 #654b36，待最后复扫。
5. P3：收入和结余数字的光学字重、分类条的长度与生成图略有区别，保留为后续视觉微调。
