# OPPO 真机验证与问题修复，2026-10-11 至 12

在 OPPO PKJ110（Android 16 / API 36、1080 × 2376、420dpi、字体 1.0）升级安装 0.2.0 ARM64 APK，使用三个独立的合成测试账本验证本地功能。按用户指定范围，只检查联网入口，不调用登录、家庭共享、同步或图片识别服务。

真机发现三类问题：隐藏金额时最近账单仍泄漏金额；关闭选项或日期选择器后背景输入框重新弹出键盘；系统字体变化后相册和相机入口失效。前两项与媒体入口修复已在真机复测。防止 Activity 重建后暴露出字体布局没有同步更新的问题，最终补丁改为由 Android 配置事件刷新字体度量和视图。手机随后断开，最终 APK 的 OPPO 安装与字体布局复测尚未完成。

## 修复实现

- **首页金额隐藏**：汇总和分类统一显示掩码，收起最近账单列表。商户自由文本也可能含金额，因此不保留最近账单的可见文字或无障碍标签；前往账单页仍可查看明细。该偏好仅承诺隐藏首页金额。
- **选择器焦点**：打开选项和原生日期选择器前调用 `Keyboard.dismiss()`，收起键盘并解除旧焦点，取消选择不会清空草稿。
- **字体与媒体选择器**：Expo 配置插件让 MainActivity 处理 `fontScale`，避免 Activity 销毁后 Expo 图片模块沿用已注销的 ActivityResultLauncher。Android 配置变化时更新 DisplayMetricsHolder 并向 JS 发送当前字体缩放；共享订阅保留最新值，使之后打开的表单也能接收正确状态。只重新创建需要布局更新的原生视图，账本控制器及表单草稿留在原组件。

生成的 Android 工程仍来自 Expo 配置，没有手改生成目录。没有修改金额计算、账本格式、同步协议或原有账本数据。

## 恢复与验证边界

测试没有清除应用数据、卸载应用或修改原有账本记录。三个测试账本、自制图片及导出文件保留在设备中。测试每日提醒已关闭，订阅和周期规则已暂停；字体恢复为 1.0，密度仍为原来的 420dpi。手机断开时停留在 OPPO-QA-PLANS 的报表页，未能恢复原先选中的账本。

实际照片拍摄、账单附件添加/查看/解除及含附件备份、资产账户改名/校准/归档、外币汇率、多币种、AA 分摊和人工 TalkBack 朗读未执行。联网服务链路不在本次授权范围内。每日通知正文通过系统通知数据核对，没有保存包含其他应用通知的截图。
